Project Overview

We will collect our own smartphone motion data, compare it to a public HAR dataset and then train machine learning models and deep learning models to recognise activities. We then test how robust the models are 
under different conditions (e.g. device placement).

Activities: walking, walking upstairs, walking downstairs (plus others from the public dataset including sitting and standing)

Device placements (group data): waist, trouser pocket and in hand.
